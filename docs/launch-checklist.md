# 全国ローンチ・チェックリスト

Hoop Matchを「全国のバスケユーザーに使ってもらう」ための公開手順と、
最初の1ヶ月にやることのリストです。上から順に進めれば公開できます。

## フェーズ1: 公開準備(1日)

- [ ] GitHub Pagesで公開する(リポジトリ Settings → Pages → Branch: main / root)
- [ ] 公開URLを確認し、`index.html` の `og:url`・`og:image`・`twitter:image` の
      ドメインを実際の公開URLに書き換える(現在はGitHub Pagesの想定URLが仮置き)
- [ ] `terms.html` と `privacy.html` の「運営者連絡先」を記入する
      (専用のGmail等を1つ作るのがおすすめ。個人の連絡先は書かない)
- [ ] iPhoneで公開URLを開き、表示・ホーム画面追加(PWA)を確認する
- [ ] LINEの自分だけのグループにURLを貼り、OGPカード(画像+タイトル)が
      正しく出るか確認する

## フェーズ2: 公開マッチング稼働(半日)

- [ ] docs/backend-setup.md の手順でSupabaseをセットアップする(無料・約30分)
- [ ] `data/config.js` にURLとanonキーを設定して再デプロイ
- [ ] 自分で公開募集を1件投稿→Supabaseで承認→別端末で表示されるか確認
- [ ] 通報→reportsテーブルに入るか確認
- [ ] (任意)GA4のプロパティを作成し、測定IDを `data/config.js` の
      `gaMeasurementId` に設定(訪問数・地域・流入元が見えるようになる)

## フェーズ3: シード(最初の募集を並べる)(継続)

空の一覧は最大の離脱要因。全国展開でも「主要都市に募集が並んでいる」状態を作る。

- [ ] 自分のチームの本物の募集を投稿する(これが最初の1件)
- [ ] 知り合いのチーム・チームメイトに依頼して、実在の募集を5〜10件集める
      (東京・大阪・名古屋・福岡など人口の多い都市圏から)
- [ ] 各募集の「共有」ボタンでLINEグループ・チームの連絡網に流してもらう
      (共有文にアプリURLが自動で付くので、受け取った人がそのまま開ける)

## フェーズ4: 告知(公開後1〜2週間)

- [ ] X(旧Twitter)にアプリ紹介を投稿(OGPカードが出るのでURLだけでも見栄えする)
- [ ] 地域のバスケLINEオープンチャット・サークル掲示板で紹介
      (宣伝ルールは各コミュニティの規約に従う)
- [ ] バスケ関連のハッシュタグ(#バスケ #練習試合募集 #バスケメンバー募集 等)で
      定期的に募集の共有文を投稿

## フェーズ5: 計測と改善(毎週)

- [ ] GA4で「どの県からのアクセスが多いか」を確認
- [ ] アクセスが多いのに募集が少ない県 = シードを足すべき県
- [ ] Supabaseの投稿数・応募数を週次でメモ(Table Editorで確認)
- [ ] 通報・削除依頼への対応(48時間以内を目安)

## 運用上の注意

- Supabase無料枠は1週間アクセスがないと一時停止することがある
  → 週1回は管理画面を開く習慣をつける(承認作業と兼ねる)
- 承認は1日1回まとめてでOK。ただし放置しすぎると投稿者が離脱するので
  24時間以内を目安に
- 利用規約・プライバシーポリシーは利用者が増える前に専門家レビューを
  (docs/legal-checklist.md参照)
